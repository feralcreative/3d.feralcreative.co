However, some patterns (such as 'Hole', 'Lines' and 'Hearts') may not print on vertical surfaces without supports.Following feedback that some users had issues stacking the caddies, the default Lip_Gap size has been increased to 0.6mm in version 1.4. Additionally, corner section options have been added to the Parts list, to allow for testing of your chosen Lip_Gap value.Some users have reported experiencing issues with 'elephant's foot', which results from their 3D printer not printing the lip recess at the expected width. This can prevent the caddies from being stacked. It may be possible to rectify this using sandpaper or a file to remove the elephant's foot, but we suggest reading this guide for some suggestions on how to prevent the issue. Alternatively, you can attempt to work around the issue by printing the caddy with a 'raft' and/or by increasing the Lip_Gap value.MaterialThis design is perfect for printing in many filaments, including PLA, PETG and ABS.Versions1.0 (20 Jul 2022) - Initial version1.1 (20 Jul 2022):Removed some redundant codeImproved heart pattern calculationChanged lid to be rotated instead of mirrored1.2 (3 Aug 2022):Increased minimum Material_Thickness value to 2.5mm to ensure height of lip doesn't exceed height of recessIncreased minimum Lip_Gap to 0.1mmAdded model dimensions to console output1.3 (4 Aug 2022):Improved lip recess height calculationFixed issue with lip recess height for Material_Thickness values that were lower than the default value (4mm)Added Container Corner Section and Lid Corner Section to list of Parts to allow for testing of chosen Lip_Gap value1.4 (5 Aug 2022):Increased default Lip_Gap to 0.6mmPrintingRecommended slicer settings:Resolution: 0.1mm - 0.2mmInfill: ~20%Supports: Generally not required.
