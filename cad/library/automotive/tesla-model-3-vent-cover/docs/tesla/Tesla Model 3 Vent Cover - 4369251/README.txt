Tesla Model 3 Vent Cover by rhilado_maker on Thingiverse: https://www.thingiverse.com/thing:4369251

Summary:
This is a vent cover for the Tesla Model 3. Since it is not possible to turn off the fan air flow between the driver and passenger independently, this vent cover allows you to effectively block the air flow for either the driver or passenger.The vent cover is made up of 5 parts: left end cap, right end cap, and three middle sections. I used 2-56 threaded rods to hold all the pieces together, then wrapped the cover with 3M brushed black vinyl. The cover can be pushed behind the center display when not being used (the vents are closed in that section). It has a slight friction fit so it shouldn't slide around. It can be slid to either the driver or passenger side, and it stops before the side mirror directional vent, also a friction fit to hold it in place.When the fan is on the higher settings (e.g. 7+), it may lift upward a little due to the air pressure, but it should still hold in place and block the air. Print all the parts vertical, if possible. no supports needed. I printed using ABS, 100% fill with raft. Other material and settings can be used, of course.Update: I've fixed the left piece (it was missing the tab), and added a "long" version, which is a single long middle piece (if you have a large format printer), and end cap (x2). The end caps can be attached using 2-56 screws.
